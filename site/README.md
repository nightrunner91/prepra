# Prepra Site

This directory contains the Astro application that powers the Prepra learning platform.

For full project documentation, setup instructions, and contribution guidelines, see the [README](../README.md).

## Motion

Правила анимации и перехода между страницами — в [MOTION.md](./MOTION.md).

## Quick commands

```bash
cd site
npm install
npm run dev
npm run check:styles   # запрет произвольных размеров шрифта и цветов
npm run test           # unit/regression-тесты (vitest + jsdom)
npm run icons          # пересобрать favicon, PNG-иконки и manifest.json
```
