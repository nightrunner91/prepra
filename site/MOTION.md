# Motion-спецификация

Короткий набор правил для анимации интерфейса Prepra. Относится ко всему
сайту; реализация переходов между страницами живёт в
`src/styles/global.css`.

## Характер

Спокойный, «бумажный» брутализм: движение объясняет смену состояния, а не
развлекает. Интерфейс должен ощущаться быстрым, собранным и предсказуемым.
Ориентир по интенсивности — 3 из 10: движение заметно, но не превращается
в аттракцион.

## Переход между страницами

Навигация остаётся документной. Браузер загружает новую страницу сам, а
View Transitions API только сшивает кадры старой и новой страницы. Это даёт
плавный переход без SPA-роутера: скрипты не нужно переинициализировать,
фокус и заголовок документа ведут себя как при обычном переходе.

| Параметр | Значение |
| --- | --- |
| Вход страницы | `260ms`, `--ease-out` (`cubic-bezier(0.23, 1, 0.32, 1)`) |
| Выход страницы | `160ms`, `--ease-in-out` (`cubic-bezier(0.77, 0, 0.175, 1)`) |
| Смещение | `14px` по вертикали: новый контент поднимается снизу, старый уходит вверх на `7px` |
| Прозрачность | вход `0 → 1`, выход `1 → 0` |
| Шапка | остаётся на месте (`view-transition-name: site-header`) |

Направление всегда вертикальное — «новый лист бумаги поверх старого».
Горизонтальные слайды «вперёд/назад» здесь не используются: в документации
важнее глубина чтения, а не история навигации, и вертикальное смещение
одинаково читается при любом переходе.

### Что анимируется

- Переход между документами (ссылки в шапке, карточки разделов, статьи,
  практика, интервью).
- Смена цветового тона секции: фон старой и новой страницы перетекает
  вместе с контентом, поэтому переход между разделами не «щёлкает».

### Что не анимируется

- Внутренние действия внутри React-островов: выбор задачи, ответ, смена
  таба, фильтрация, переключение темы. Это быстрые действия, им достаточно
  существующих микро-переходов (`100–200ms`, hover/active).
- Якорные ссылки внутри одной страницы.
- Шапка сайта: она общая для всех страниц и не должна «прыгать».

## Reduced motion

При `prefers-reduced-motion: reduce` переходы страниц отключаются полностью:
страница меняется сразу, без смещения и затухания. Остальные анимации
(hero, появление карточек) уже отключаются существующим блоком в
`global.css`.

## Доступность

- Навигация — реальная смена документа, поэтому скринридер объявляет новый
  `<title>`, а история и кнопка «Назад» работают штатно.
- View Transitions не меняет layout: снапшоты рисуются поверх страницы,
  скачков контента и потери позиции скролла нет.
- Анимируются только `opacity` и `transform` (композиторные свойства), без
  `width`, `height`, `top` и `left`.

## Fallback

Если браузер не поддерживает cross-document View Transitions, CSS-правила
игнорируются и навигация происходит мгновенно — без ошибок и лишнего JS.
