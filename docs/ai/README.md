## Начни с базы

1. **[Ментальная модель LLM](./ai-mental-model.md)** — токены, контекстное окно, температура, latency
2. **[Паттерны промптинга](./ai-prompting-patterns.md)** — few-shot, CoT, chaining — язык формулирования задач
3. **[AI в рабочем процессе разработчика](./ai-dev-workflow.md)** — генерация кода, review, рефакторинг, тесты
4. **[AI-агенты в работе фронтендера](./ai-agent-workflow.md)** — спецификация → генерация → проверка, AGENTS.md, когда агент врёт
