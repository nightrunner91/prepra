# Хранилища

Раздел объединяет три аспекта работы с данными на клиенте: браузерные хранилища, клиентское состояние через популярные стейт-менеджеры и серверное состояние через TanStack Query.

## Начни с базы

1. **[Локальные хранилища данных](./client-storage.md)** — localStorage, sessionStorage, cookies, IndexedDB, безопасность и ограничения.
2. **[Redux Toolkit](./redux.md)** — createSlice, Immer, createAsyncThunk, RTK Query, миграция с классического Redux.
3. **[Zustand](./zustand.md)** — лёгкий стор, селекторы, мидлвары, миграция с Redux.
4. **[TanStack Query](./tanstack-query.md)** — кэширование, мутации, фоновое обновление, продвинутые сценарии.
5. **[Pinia](./pinia.md)** — официальный стейт-менеджер Vue 3, defineStore, геттеры, плагины, миграция с Vuex.
